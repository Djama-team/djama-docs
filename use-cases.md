# Djama — сценарии использования (на согласование с преподавателем)

**Акторы:** Пользователь, Администратор группы (пользователь с ролью Admin), Система (уведомления).

## Основные сценарии
| № | Сценарий | Кратко |
|---|---|---|
| UC-01 | Регистрация | логин, имя, e-mail, пароль → сразу вход в приложение |
| UC-02 | Вход / выход | логин или e-mail + пароль, JWT-токен |
| UC-03 | Профиль | изменить отображаемое имя и «о себе», выбрать язык (RU/FR) |
| UC-04 | Поиск пользователей | по логину или имени (от 2 символов) |
| UC-05 | Контакты | добавить, удалить, написать контакту |
| UC-06 | Блокировка | заблокировать / разблокировать; переписка между ними невозможна |
| UC-07 | Личный чат | открыть или создать чат с пользователем |
| UC-08 | Сообщения в реальном времени | отправка, мгновенная доставка всем участникам (SignalR) |
| UC-09 | Статусы прочтения | ✓ отправлено, ✓✓ прочитано; счётчик непрочитанных |
| UC-10 | «Печатает…» и онлайн-статус | события в реальном времени |
| UC-11 | Создание группы | название + участники из контактов, создатель — админ |
| UC-12 | Управление группой | добавить / исключить, назначить или снять админа, переименовать, выйти |
| UC-13 | Реакции | быстрые эмодзи под сообщением |
| UC-14 | Удаление своего сообщения | «мягкое» удаление, видно всем участникам |
| UC-15 | Уведомления | пропущенные сообщения (если офлайн), добавление в группу |
| UC-16 | История | подгрузка старых сообщений порциями по 50 |
| UC-17 | Добавление участников в группу | админ ищет любого пользователя по имени или логину и добавляет его (не только из контактов) |
| UC-18 | Ответ на сообщение и редактирование | цитата исходного сообщения; изменение своего сообщения в течение 15 минут |
| UC-19 | Фото, документы, видео | предпросмотр с подписью, перетаскивание файлов, вставка из буфера, просмотр фото на весь экран |
| UC-20 | Голосовые сообщения | запись с микрофона, воспроизведение с волной и скоростью 1×/1.5×/2× |
| UC-21 | Голосовые и видеозвонки 1-на-1 | входящий звонок, принять/отклонить, микрофон и камера, длительность; итог звонка в чате |
| UC-22 | Тёмная тема и два языка | RU/FR, светлая/тёмная/системная тема |

## Негативные сценарии
| № | Ситуация | Ожидаемое поведение |
|---|---|---|
| N-01 | Неверный пароль | 401, понятное сообщение, поля не очищаются |
| N-02 | Логин или e-mail уже заняты | 409 `CONFLICT` |
| N-03 | Пустое сообщение / более 4000 символов | 400 `VALIDATION`, сообщение не сохраняется |
| N-04 | Отправка заблокированному (или от него) | 403 `BLOCKED` |
| N-05 | Не участник пытается читать или писать в чат | 403 `FORBIDDEN` |
| N-06 | Не админ управляет группой | 403 `FORBIDDEN` |
| N-07 | Последний админ выходит из группы | права админа получает самый «старый» участник; пустая группа удаляется |
| N-08 | Потеря соединения | баннер «Переподключаемся…», отправка через REST, после возврата — перезагрузка данных |
| N-09 | Истёкший токен | 401 → автоматический выход на страницу входа |
| N-10 | Чат с самим собой / добавить себя в контакты | 400 `VALIDATION` |
| N-11 | Файл больше 25 МБ или более 10 файлов | 400 `VALIDATION`, файл не сохраняется |
| N-12 | Скачивание файла не участником чата или удалённого сообщения | 403 / 404 |
| N-13 | Редактирование чужого сообщения или позже чем через 15 минут | 403 `FORBIDDEN` |
| N-14 | Звонок пользователю не в сети | 409 `OFFLINE`, в чате «Пропущенный звонок» |
| N-15 | Звонок занятому пользователю | 409 `BUSY` |
| N-16 | Нет доступа к микрофону или камере | понятное сообщение, звонок или запись не начинаются |
| N-17 | Закрытие вкладки во время звонка | собеседнику приходит «Звонок завершён» |
