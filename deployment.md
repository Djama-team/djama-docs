# Djama — Руководство по развёртыванию

## Требования
- Сервер Ubuntu 22.04 (или Arch Linux с 8 ГБ ОЗУ)
- Docker + Docker Compose plugin
- Git

## Установка

### 1. Клонировать 3 репозитория рядом
```bash
mkdir ~/djama && cd ~/djama
git clone https://github.com/Djama-team/djama-backend.git
git clone https://github.com/Djama-team/djama-frontend.git
git clone https://github.com/Djama-team/djama-docs.git
