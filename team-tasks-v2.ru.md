# Djama v2 — что нового и кто что доводит

## Что добавлено в версии 2
- **Группы:** добавление участников поиском любого пользователя (раньше — только из контактов), общее окно «Новая группа» с поиском.
- **Сообщения:** ответ (цитата), редактирование (15 минут), фото / видео / документы с предпросмотром и подписью, перетаскивание и вставка из буфера, просмотр фото, **голосовые сообщения** (запись, волна, скорость), эмодзи-панель, группировка сообщений, кнопка «вниз», сохранение позиции прокрутки.
- **Звонки 1-на-1:** голосовые и видео (WebRTC), входящий звонок с рингтоном, микрофон и камера, итог звонка в чате («Пропущенный», «Отклонён», длительность).
- **Интерфейс:** боковая панель навигации, поиск и фильтры чатов (все / непрочитанные / группы), тёмная тема, всплывающие уведомления, адаптивная версия для телефона.
- **База данных:** новые столбцы в `messages` и `attachments`. Существующая база обновляется **автоматически** при запуске (`DbUpgrade.cs`), данные версии 1 сохраняются.

## Известные ограничения версии 2
- Звонки — только 1-на-1 (без групповых), без демонстрации экрана.
- Без TURN-сервера звонок может не соединиться между разными сетями.
- Токен для просмотра файлов передаётся в адресе (`?access_token=`) — допустимо для учебного проекта, для продакшена нужны подписанные короткоживущие ссылки.
- Файлы хранятся на диске сервера (volume `uploads`), без антивирусной проверки.
